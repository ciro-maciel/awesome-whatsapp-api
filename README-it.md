## Ufficiale di Meta

L'unica strada che Meta consente alle aziende per parlare con i clienti in modo programmatico.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - La documentazione della Cloud API: invio, ricezione, modelli di messaggio e webhook. `ufficiale` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Come Meta addebita i messaggi e per categoria di conversazione. `ufficiale`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Ciò che è consentito e vietato alle aziende su WhatsApp. `ufficiale`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - I termini di servizio per gli account business. `ufficiale`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - Il sito di WhatsApp per le aziende, con app e piattaforma. `ufficiale`

## Librerie per l'API ufficiale

Open source, per la Cloud API di Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Libreria TypeScript leggera e senza dipendenze per la Cloud API. `open source` `gratis`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Invio e ricezione tramite Cloud API in PHP. `open source` `gratis`

## Provider dell'API ufficiale

Partner di Meta che rivendono e gestiscono l'API. In ordine alfabetico.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Accesso diretto all'API ufficiale, con addebito per numero. `API` `a pagamento`
- [Blip](https://go.mymarketing.click/wapi-blip) - Piattaforma brasiliana per assistenza clienti e chatbot su WhatsApp. `a pagamento`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API di messaggistica con WhatsApp e chatbot. `API` `a pagamento`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - API omnichannel con WhatsApp. `API` `a pagamento`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp tramite l'API di Twilio, insieme a SMS e voce. `API` `a pagamento`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Piattaforma brasiliana di comunicazione con WhatsApp, SMS ed e-mail. `a pagamento`

## Librerie non ufficiali

Si connettono come se fossero WhatsApp Web. Meta non autorizza questo uso per le aziende e il numero può essere bannato; sono pensate per uso personale, test e automazioni proprie.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API in TypeScript che parla il protocollo di WhatsApp Web tramite socket, senza browser. `open source` `gratis`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Client Node.js che si connette a WhatsApp Web in un browser controllato. `open source` `gratis`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Libreria Go per la API multi-dispositivo di WhatsApp Web. `open source` `gratis`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Automazione di WhatsApp Web in Node.js e TypeScript, da un team brasiliano. `open source` `gratis`
- [Venom](https://go.mymarketing.click/wapi-venom) - Sistema in JavaScript per creare bot su WhatsApp Web. `open source` `gratis`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - Riga di comando in Go che si connette come dispositivo di WhatsApp Web, salva la cronologia in un SQLite locale con ricerca e invia messaggi, media e gruppi, per terminale, script e agenti IA. `open source` `gratis`

## Server REST pronti all'uso

Avviano un'API HTTP sopra le librerie sopra elencate. Valgono le stesse restrizioni.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API di integrazione con WhatsApp, open source e fatta in Brasile. `open source` `gratis`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API con più motori e più sessioni. `open source` `gratis`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - API REST self-hosted basata su WPPConnect. `open source` `gratis`

## Etichette

Ogni voce dice di cosa si tratta. Le etichette a lato aiutano a scegliere: ufficiale quando arriva da chi definisce lo standard, open source quando il codice è pubblicato, gratis o a pagamento in base al modello d'uso, API e SDK in base al modo di integrare. Le voci con l'etichetta "dell'autore" sono realizzate da Ciro Cesar Maciel e seguono le stesse regole di tutte le altre.
