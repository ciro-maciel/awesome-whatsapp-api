## Resmi dari Meta

Satu-satunya jalur yang diizinkan Meta bagi perusahaan untuk berbicara dengan pelanggan secara terprogram.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - Dokumentasi Cloud API: pengiriman, penerimaan, template pesan, dan webhook. `resmi` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Cara Meta menagih per pesan dan per kategori percakapan. `resmi`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Apa yang boleh dan tidak boleh dilakukan perusahaan di WhatsApp. `resmi`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Ketentuan layanan untuk akun bisnis. `resmi`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - Situs WhatsApp untuk bisnis, dengan aplikasi dan platformnya. `resmi`

## Pustaka untuk API resmi

Terbuka, untuk Cloud API dari Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Pustaka TypeScript ringan tanpa dependensi untuk Cloud API. `open source` `gratis`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Pengiriman dan penerimaan lewat Cloud API dengan PHP. `open source` `gratis`

## Penyedia API resmi

Mitra Meta yang menjual ulang dan mengoperasikan API. Urut abjad.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Akses langsung ke API resmi, ditagih per nomor. `API` `berbayar`
- [Blip](https://go.mymarketing.click/wapi-blip) - Platform layanan pelanggan Brasil dan chatbot di WhatsApp. `berbayar`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API pesan dengan WhatsApp dan chatbot. `API` `berbayar`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - API omnichannel dengan WhatsApp. `API` `berbayar`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp lewat API Twilio, bersama SMS dan suara. `API` `berbayar`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Platform komunikasi Brasil dengan WhatsApp, SMS, dan email. `berbayar`

## Pustaka tidak resmi

Terhubung seolah-olah sebagai WhatsApp Web. Meta tidak mengizinkan penggunaan ini untuk bisnis dan nomor bisa diblokir; cocok untuk pemakaian pribadi, uji coba, dan otomatisasi sendiri.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API TypeScript yang berbicara dengan protokol WhatsApp Web lewat socket, tanpa browser. `open source` `gratis`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Klien Node.js yang terhubung ke WhatsApp Web di browser terkendali. `open source` `gratis`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Pustaka Go untuk API multi-perangkat WhatsApp Web. `open source` `gratis`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Otomatisasi WhatsApp Web dengan Node.js dan TypeScript, dari tim Brasil. `open source` `gratis`
- [Venom](https://go.mymarketing.click/wapi-venom) - Sistem JavaScript untuk membuat bot di WhatsApp Web. `open source` `gratis`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - Alat baris perintah berbasis Go yang terhubung sebagai perangkat WhatsApp Web, menyimpan riwayat di SQLite lokal dengan pencarian, serta mengirim pesan, media, dan grup, untuk terminal, skrip, dan agen AI. `open source` `gratis`

## Server REST siap pakai

Menjalankan API HTTP di sekitar pustaka di atas. Batasan yang sama berlaku.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API integrasi WhatsApp, open source, dibuat di Brasil. `open source` `gratis`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API dengan banyak engine dan banyak sesi. `open source` `gratis`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - API REST self-hosted di atas WPPConnect. `open source` `gratis`

## Label

Setiap item menjelaskan apa itu. Label di sampingnya membantu memilih: resmi jika berasal dari pihak yang menentukan standarnya, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, API dan SDK menurut cara integrasinya.
