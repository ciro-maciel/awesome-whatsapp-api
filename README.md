## Oficial da Meta

O único caminho que a Meta permite para empresas falarem com clientes por programa.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - A documentação da Cloud API: envio, recebimento, modelos de mensagem e webhooks. `oficial` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Como a Meta cobra por mensagem e por categoria de conversa. `oficial`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - O que é permitido e proibido para empresas no WhatsApp. `oficial`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Os termos de serviço para contas comerciais. `oficial`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - O site do WhatsApp para empresas, com o aplicativo e a plataforma. `oficial`

## Bibliotecas para a API oficial

Abertas, para a Cloud API da Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Biblioteca TypeScript leve e sem dependências para a Cloud API. `código aberto` `grátis`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Envio e recebimento pela Cloud API em PHP. `código aberto` `grátis`

## Provedores da API oficial

Parceiros da Meta que revendem e operam a API. Em ordem alfabética.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Acesso direto à API oficial, com cobrança por número. `API` `pago`
- [Blip](https://go.mymarketing.click/wapi-blip) - Plataforma brasileira de atendimento e chatbots no WhatsApp. `pago`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API de mensagens com WhatsApp e chatbots. `API` `pago`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - API omnichannel com WhatsApp. `API` `pago`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp pela API da Twilio, junto com SMS e voz. `API` `pago`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Plataforma brasileira de comunicação com WhatsApp, SMS e e-mail. `pago`

## Bibliotecas não oficiais

Conectam como se fossem o WhatsApp Web. A Meta não autoriza esse uso para empresas e o número pode ser banido; servem para uso pessoal, testes e automações próprias.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API em TypeScript que fala o protocolo do WhatsApp Web por socket, sem navegador. `código aberto` `grátis`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Cliente Node.js que conecta pelo WhatsApp Web num navegador controlado. `código aberto` `grátis`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Biblioteca Go para a API multiaparelho do WhatsApp Web. `código aberto` `grátis`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Automação do WhatsApp Web em Node.js e TypeScript, de um time brasileiro. `código aberto` `grátis`
- [Venom](https://go.mymarketing.click/wapi-venom) - Sistema em JavaScript para criar bots no WhatsApp Web. `código aberto` `grátis`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - Linha de comando em Go que se conecta como um aparelho do WhatsApp Web, guarda o histórico num SQLite local com busca e envia mensagens, mídia e grupos, para terminal, scripts e agentes de IA. `código aberto` `grátis`

## Servidores REST prontos

Sobem uma API HTTP em volta das bibliotecas acima. Valem as mesmas restrições.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API de integração com WhatsApp, de código aberto e feita no Brasil. `código aberto` `grátis`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API com vários motores e várias sessões. `código aberto` `grátis`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - API REST auto-hospedada sobre o WPPConnect. `código aberto` `grátis`

- [QR Code do WhatsApp](https://go.mymarketing.click/wapi-qr-code-do-whatsapp) - O QR code que abre a sua conversa com a mensagem pronta, em PNG ou SVG. `grátis` `do autor`
- [Nome, descrição e regras para grupo](https://go.mymarketing.click/wapi-nome-descricao-e-regras-para-grupo) - Ideias de nome, a descrição e as regras prontas para colar num grupo. `grátis` `do autor`

## Etiquetas

Cada item diz o que é. As etiquetas ao lado ajudam a escolher: oficial quando vem de quem define o padrão, código aberto quando o código está publicado, grátis ou pago pelo modelo de uso, API e SDK pelo jeito de integrar. Os itens com a etiqueta "do autor" são feitos por Ciro Cesar Maciel e seguem as mesmas regras de todos os outros.
