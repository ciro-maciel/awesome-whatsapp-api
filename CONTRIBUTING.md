# Como contribuir

Obrigado por ajudar. A lista só é útil se for verdadeira e estiver em dia.

## O que entra

- **Funciona hoje.** O endereço abre e o item faz o que diz.
- **Atende ao tema da lista.**
- **Tem página oficial ou repositório.** Nada de link para revenda ou cópia.
- **Uma frase que diz o que faz**, sem adjetivo de propaganda ("o melhor", "revolucionário").

Ninguém paga para entrar. Concorrentes entram com as mesmas regras de todos, inclusive dos itens
com a etiqueta "do autor".

## Como mandar

1. Edite só o `data/list.json`: acrescente o item na categoria certa, em ordem alfabética, com
   `name`, `url`, `description` (em português), `tags` e `added` (a data de hoje, `AAAA-MM-DD`).
2. Abra o pull request. Os READMEs das 15 línguas, o JSON e o RSS são gerados sozinhos depois do merge.

Se preferir, abra uma issue com o formulário de nova inclusão, e o item é incluído por quem mantém a lista.

## Etiquetas

`oficial` (de quem define o padrão), `codigo-aberto`, `gratis`, `pago`, `api`, `sdk`. Use as que se
aplicam; não invente etiqueta nova sem abrir uma issue antes.

## Se você faz parte do projeto

Diga no pull request. Não impede a inclusão, só deixa a decisão transparente.
