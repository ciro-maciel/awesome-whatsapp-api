Pour ceux qui veulent envoyer et recevoir des messages WhatsApp par programme et doivent choisir la voie avant d'écrire du code. L'API officielle est la seule autorisée pour les entreprises ; les bibliothèques non officielles fonctionnent, mais le numéro peut être banni. La liste sépare les deux et le précise dans chaque section.

## Officiel de Meta

Le seul moyen que Meta autorise aux entreprises pour parler à leurs clients par programme.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - La documentation de la Cloud API : envoi, réception, modèles de message et webhooks. `officiel` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Comment Meta facture par message et par catégorie de conversation. `officiel`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Ce qui est permis et interdit aux entreprises sur WhatsApp. `officiel`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Les conditions d'utilisation des comptes professionnels. `officiel`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - Le site de WhatsApp pour les entreprises, avec l'application et la plateforme. `officiel`

## Bibliothèques pour l'API officielle

Ouvertes, pour la Cloud API de Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Bibliothèque TypeScript légère et sans dépendances pour la Cloud API. `open source` `gratuit`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Envoi et réception via la Cloud API en PHP. `open source` `gratuit`

## Fournisseurs de l'API officielle

Partenaires de Meta qui revendent et exploitent l'API. Par ordre alphabétique.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Accès direct à l'API officielle, facturé par numéro. `API` `payant`
- [Blip](https://go.mymarketing.click/wapi-blip) - Plateforme brésilienne de service client et de chatbots sur WhatsApp. `payant`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API de messagerie avec WhatsApp et chatbots. `API` `payant`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - API omnicanale avec WhatsApp. `API` `payant`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp via l'API de Twilio, avec SMS et voix. `API` `payant`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Plateforme brésilienne de communication avec WhatsApp, SMS et e-mail. `payant`

## Bibliothèques non officielles

Elles se connectent comme WhatsApp Web. Meta n'autorise pas cet usage pour les entreprises et le numéro peut être banni ; elles servent à un usage personnel, aux tests et à ses propres automatisations.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API en TypeScript qui parle le protocole de WhatsApp Web par socket, sans navigateur. `open source` `gratuit`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Client Node.js qui se connecte à WhatsApp Web dans un navigateur contrôlé. `open source` `gratuit`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Bibliothèque Go pour l'API multi-appareils de WhatsApp Web. `open source` `gratuit`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Automatisation de WhatsApp Web en Node.js et TypeScript, par une équipe brésilienne. `open source` `gratuit`
- [Venom](https://go.mymarketing.click/wapi-venom) - Système en JavaScript pour créer des bots sur WhatsApp Web. `open source` `gratuit`
- [wacli](https://go.mymarketing.click/wapi-wacli) - Ligne de commande pour synchroniser, rechercher et envoyer des messages. `open source` `gratuit`

## Serveurs REST prêts à l'emploi

Ils exposent une API HTTP autour des bibliothèques ci-dessus. Mêmes restrictions.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API d'intégration WhatsApp, open source et développée au Brésil. `open source` `gratuit`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API avec plusieurs moteurs et plusieurs sessions. `open source` `gratuit`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - API REST auto-hébergée basée sur WPPConnect. `open source` `gratuit`

## Service client

Boîte de réception pour que l'équipe réponde.

- [Chatwoot](https://go.mymarketing.click/wapi-chatwoot) - Centre de support open source, avec WhatsApp, e-mail et chat sur le site. `open source` `gratuit`

- [QR Code do WhatsApp](https://go.mymarketing.click/wapi-qr-code-do-whatsapp) - Le QR code qui ouvre votre conversation avec le message prêt, en PNG ou SVG. `gratuit` `de l'auteur`
- [Nome, descrição e regras para grupo](https://go.mymarketing.click/wapi-nome-descricao-e-regras-para-grupo) - Idées de nom, la description et les règles prêtes à coller dans un groupe. `gratuit` `de l'auteur`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de celui qui définit le standard, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la façon d'intégrer. Les éléments avec l'étiquette « de l'auteur » sont réalisés par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
