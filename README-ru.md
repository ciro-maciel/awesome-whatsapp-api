## Официальное от Meta

Единственный путь, который Meta разрешает компаниям общаться с клиентами программно.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - Документация Cloud API: отправка, получение, шаблоны сообщений и webhooks. `официальный` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Как Meta берёт плату за сообщение и за категорию диалога. `официальный`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Что компаниям разрешено и запрещено в WhatsApp. `официальный`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Условия использования для бизнес-аккаунтов. `официальный`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - Сайт WhatsApp для бизнеса, с приложением и платформой. `официальный`

## Библиотеки для официального API

Открытые, для Cloud API от Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Лёгкая библиотека на TypeScript без зависимостей для Cloud API. `открытый код` `бесплатно`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Отправка и получение через Cloud API на PHP. `открытый код` `бесплатно`

## Провайдеры официального API

Партнёры Meta, которые перепродают и обслуживают API. По алфавиту.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Прямой доступ к официальному API с оплатой за номер. `API` `платно`
- [Blip](https://go.mymarketing.click/wapi-blip) - Бразильская платформа для обслуживания клиентов и чат-ботов в WhatsApp. `платно`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API сообщений для WhatsApp и чат-ботов. `API` `платно`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - Омниканальный API с WhatsApp. `API` `платно`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp через API Twilio, вместе с SMS и голосом. `API` `платно`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Бразильская платформа коммуникаций с WhatsApp, SMS и e-mail. `платно`

## Неофициальные библиотеки

Подключаются так, будто это WhatsApp Web. Meta не разрешает такое использование компаниям, и номер могут заблокировать; подходят для личного пользования, тестов и собственных автоматизаций.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API на TypeScript, который говорит по протоколу WhatsApp Web через сокет, без браузера. `открытый код` `бесплатно`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Клиент Node.js, который подключается к WhatsApp Web в управляемом браузере. `открытый код` `бесплатно`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Библиотека на Go для многоустройственного API WhatsApp Web. `открытый код` `бесплатно`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Автоматизация WhatsApp Web на Node.js и TypeScript от бразильской команды. `открытый код` `бесплатно`
- [Venom](https://go.mymarketing.click/wapi-venom) - Система на JavaScript для создания ботов в WhatsApp Web. `открытый код` `бесплатно`
- [wacli](https://go.mymarketing.click/wapi-wacli) - Командная строка для синхронизации, поиска и отправки сообщений. `открытый код` `бесплатно`

## Готовые REST-серверы

Поднимают HTTP API поверх библиотек выше. Действуют те же ограничения.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API интеграции с WhatsApp, с открытым кодом и сделанный в Бразилии. `открытый код` `бесплатно`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API с несколькими движками и несколькими сессиями. `открытый код` `бесплатно`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - Самохостируемый REST API на базе WPPConnect. `открытый код` `бесплатно`

Без регистрации, в браузере.

- [Gerador de link de WhatsApp](https://go.mymarketing.click/wapi-gerador-de-link-de-whatsapp) - Ссылка wa.me с уже написанным сообщением и QR code для печати. `бесплатно` `от автора`
- [QR Code do WhatsApp](https://go.mymarketing.click/wapi-qr-code-do-whatsapp) - QR code, который открывает ваш чат с готовым сообщением, в PNG или SVG. `бесплатно` `от автора`
- [Nome, descrição e regras para grupo](https://go.mymarketing.click/wapi-nome-descricao-e-regras-para-grupo) - Идеи названия, описание и правила, готовые для вставки в группу. `бесплатно` `от автора`

## Метки

Каждый пункт говорит, что это такое. Метки рядом помогают выбрать: официальный — когда это от тех, кто задаёт стандарт, открытый код — когда код опубликован, бесплатно или платно — по модели использования, API и SDK — по способу интеграции. Пункты с меткой "от автора" сделаны Сиро Сезаром Мачелом и подчиняются тем же правилам, что и все остальные.
