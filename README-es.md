Para quienes quieren enviar y recibir WhatsApp por programa y necesitan elegir el camino antes de escribir código. La API oficial es la única permitida para empresas; las bibliotecas no oficiales funcionan, pero el número puede ser baneado. La lista separa las dos opciones y lo indica en cada sección.

## Oficial de Meta

El único camino que Meta permite a las empresas para hablar con clientes mediante programa.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - La documentación de la Cloud API: envío, recepción, plantillas de mensaje y webhooks. `oficial` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Cómo cobra Meta por mensaje y por categoría de conversación. `oficial`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Qué está permitido y prohibido para empresas en WhatsApp. `oficial`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Los términos de servicio para cuentas comerciales. `oficial`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - El sitio de WhatsApp para empresas, con la aplicación y la plataforma. `oficial`

## Bibliotecas para la API oficial

Abiertas, para la Cloud API de Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Biblioteca TypeScript liviana y sin dependencias para la Cloud API. `código abierto` `gratis`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Envío y recepción por la Cloud API en PHP. `código abierto` `gratis`

## Proveedores de la API oficial

Socios de Meta que revenden y operan la API. En orden alfabético.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Acceso directo a la API oficial, con cobro por número. `API` `de pago`
- [Blip](https://go.mymarketing.click/wapi-blip) - Plataforma brasileña de atención y chatbots en WhatsApp. `de pago`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - API de mensajes con WhatsApp y chatbots. `API` `de pago`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - API omnicanal con WhatsApp. `API` `de pago`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp por la API de Twilio, junto con SMS y voz. `API` `de pago`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Plataforma brasileña de comunicación con WhatsApp, SMS y correo electrónico. `de pago`

## Bibliotecas no oficiales

Se conectan como si fueran WhatsApp Web. Meta no autoriza este uso para empresas y el número puede ser baneado; sirven para uso personal, pruebas y automatizaciones propias.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API en TypeScript que habla el protocolo de WhatsApp Web por socket, sin navegador. `código abierto` `gratis`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Cliente Node.js que se conecta a WhatsApp Web en un navegador controlado. `código abierto` `gratis`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Biblioteca Go para la API multidispositivo de WhatsApp Web. `código abierto` `gratis`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Automatización de WhatsApp Web en Node.js y TypeScript, de un equipo brasileño. `código abierto` `gratis`
- [Venom](https://go.mymarketing.click/wapi-venom) - Sistema en JavaScript para crear bots en WhatsApp Web. `código abierto` `gratis`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - Herramienta de línea de comandos en Go que se conecta como un dispositivo de WhatsApp Web, guarda el historial en un SQLite local con búsqueda y envía mensajes, multimedia y grupos, para terminal, scripts y agentes de IA. `código abierto` `gratis`

## Servidores REST listos para usar

Levantan una API HTTP alrededor de las bibliotecas de arriba. Aplican las mismas restricciones.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - API de integración con WhatsApp, de código abierto y hecha en Brasil. `código abierto` `gratis`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API con varios motores y varias sesiones. `código abierto` `gratis`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - API REST autohospedada sobre WPPConnect. `código abierto` `gratis`

## Atención al cliente

Sin registro, en el navegador.

- [QR Code do WhatsApp](https://go.mymarketing.click/wapi-qr-code-do-whatsapp) - El código QR que abre tu conversación con el mensaje listo, en PNG o SVG. `gratis` `del autor`
- [Nome, descrição e regras para grupo](https://go.mymarketing.click/wapi-nome-descricao-e-regras-para-grupo) - Ideas de nombre, la descripción y las reglas listas para pegar en un grupo. `gratis` `del autor`

## Etiquetas

Cada ítem dice qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los ítems con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
