## Meta का आधिकारिक

कंपनियों के लिए ग्राहकों से प्रोग्राम के ज़रिए बात करने का एकमात्र रास्ता जो Meta अनुमति देता है।

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - Cloud API का दस्तावेज़: भेजना, पाना, message templates और webhooks। `आधिकारिक` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - Meta प्रति मैसेज और conversation की category के हिसाब से कैसे शुल्क लेता है। `आधिकारिक`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - WhatsApp पर कंपनियों के लिए क्या अनुमत है और क्या मना है। `आधिकारिक`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - बिज़नेस अकाउंट के लिए सेवा की शर्तें। `आधिकारिक`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - ऐप और प्लेटफ़ॉर्म के साथ WhatsApp for Business की वेबसाइट। `आधिकारिक`

## आधिकारिक API के लिए लाइब्रेरी

Meta की Cloud API के लिए खुली लाइब्रेरी।

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Cloud API के लिए हल्की और बिना dependencies वाली TypeScript लाइब्रेरी। `ओपन सोर्स` `मुफ़्त`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - PHP में Cloud API से मैसेज भेजना और पाना। `ओपन सोर्स` `मुफ़्त`

## आधिकारिक API के प्रदाता

Meta के partners जो API बेचते और चलाते हैं। अक्षर क्रम में।

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - नंबर के हिसाब से शुल्क के साथ आधिकारिक API तक सीधी पहुँच। `API` `पेड`
- [Blip](https://go.mymarketing.click/wapi-blip) - WhatsApp और chatbots पर ग्राहक सहायता के लिए ब्राज़ीली प्लेटफ़ॉर्म। `पेड`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - WhatsApp और chatbots के साथ मैसेज API। `API` `पेड`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - WhatsApp के साथ omnichannel API। `API` `पेड`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - Twilio API के ज़रिए WhatsApp, SMS और voice के साथ। `API` `पेड`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - WhatsApp, SMS और ईमेल के लिए ब्राज़ीली कम्युनिकेशन प्लेटफ़ॉर्म। `पेड`

## गैर-आधिकारिक लाइब्रेरी

ये WhatsApp Web की तरह जुड़ती हैं। Meta कंपनियों के लिए इस उपयोग की अनुमति नहीं देता और नंबर बैन हो सकता है; इन्हें निजी उपयोग, टेस्ट और अपने ऑटोमेशन के लिए इस्तेमाल करें।

- [Baileys](https://go.mymarketing.click/wapi-baileys) - TypeScript में API जो बिना ब्राउज़र के socket के ज़रिए WhatsApp Web का protocol बोलता है। `ओपन सोर्स` `मुफ़्त`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Node.js क्लाइंट जो नियंत्रित ब्राउज़र में WhatsApp Web से जुड़ता है। `ओपन सोर्स` `मुफ़्त`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - WhatsApp Web की multi-device API के लिए Go लाइब्रेरी। `ओपन सोर्स` `मुफ़्त`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Node.js और TypeScript में WhatsApp Web का ऑटोमेशन, एक ब्राज़ीली टीम का। `ओपन सोर्स` `मुफ़्त`
- [Venom](https://go.mymarketing.click/wapi-venom) - WhatsApp Web पर bots बनाने के लिए JavaScript सिस्टम। `ओपन सोर्स` `मुफ़्त`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - WhatsApp Web का एक डिवाइस बनकर जुड़ने वाला Go में लिखा कमांड-लाइन टूल, जो बातचीत का इतिहास लोकल SQLite में सेव करता है, उसमें खोज की सुविधा देता है, और मैसेज, मीडिया व ग्रुप भेजता है। यह टर्मिनल, स्क्रिप्ट और AI एजेंट के लिए है। `ओपन सोर्स` `मुफ़्त`
