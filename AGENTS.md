# Para agentes de IA que contribuem com esta lista

- Edite só `data/list.json`. Os arquivos `README*.md`, `i18n/`, `links.json`, `dist/` e `feed/` são
  gerados pelo workflow `publish-list.yml` depois do merge; não os edite à mão.
- Antes de incluir, confira que o endereço abre hoje e que o item ainda não está na lista
  (procure pelo nome e pelo domínio).
- Cada item: `name`, `url` (a página oficial ou o repositório), `description` (uma frase em
  português, dizendo o que faz, sem propaganda), `tags` entre `oficial`, `codigo-aberto`, `gratis`,
  `pago`, `api`, `sdk`, e `added` com a data de hoje (`AAAA-MM-DD`).
- Mantenha a ordem alfabética dentro da categoria. Categoria nova só com uma issue antes.
- Se a pessoa que pediu faz parte do projeto, diga isso no pull request.
- A skill `.claude/skills/curador` descreve o mesmo passo a passo para o Claude Code.
