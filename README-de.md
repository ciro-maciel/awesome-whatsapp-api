Die offizielle API ist die einzige, die Unternehmen erlaubt; inoffizielle Bibliotheken funktionieren zwar, aber die Nummer kann gesperrt werden. Die Liste trennt beide und sagt das in jedem Abschnitt.

## Offiziell von Meta

Der einzige Weg, den Meta Unternehmen erlaubt, programmatisch mit Kunden zu sprechen.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - Die Dokumentation der Cloud API: Senden, Empfangen, Nachrichtenvorlagen und Webhooks. `offiziell` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - So berechnet Meta die Kosten pro Nachricht und pro Gesprächskategorie. `offiziell`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - Was Unternehmen auf WhatsApp erlaubt und verboten ist. `offiziell`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - Die Nutzungsbedingungen für Geschäftskonten. `offiziell`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - Die WhatsApp-Seite für Unternehmen, mit App und Plattform. `offiziell`

## Bibliotheken für die offizielle API

Offen, für die Cloud API von Meta.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Schlanke TypeScript-Bibliothek ohne Abhängigkeiten für die Cloud API. `Open Source` `kostenlos`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Senden und Empfangen über die Cloud API in PHP. `Open Source` `kostenlos`

## Anbieter der offiziellen API

Partner von Meta, die die API weiterverkaufen und betreiben. Alphabetisch sortiert.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Direkter Zugang zur offiziellen API, mit Abrechnung pro Nummer. `API` `kostenpflichtig`
- [Blip](https://go.mymarketing.click/wapi-blip) - Brasilianische Plattform für Kundenservice und Chatbots auf WhatsApp. `kostenpflichtig`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - Nachrichten-API mit WhatsApp und Chatbots. `API` `kostenpflichtig`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - Omnichannel-API mit WhatsApp. `API` `kostenpflichtig`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp über die API von Twilio, zusammen mit SMS und Sprache. `API` `kostenpflichtig`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Brasilianische Plattform für Kommunikation mit WhatsApp, SMS und E-Mail. `kostenpflichtig`

## Inoffizielle Bibliotheken

Verbinden sich, als wären sie WhatsApp Web. Meta erlaubt diese Nutzung für Unternehmen nicht, und die Nummer kann gesperrt werden. Geeignet für private Nutzung, Tests und eigene Automatisierungen.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - API in TypeScript, die das WhatsApp-Web-Protokoll per Socket spricht, ohne Browser. `Open Source` `kostenlos`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Node.js-Client, der sich über WhatsApp Web in einem gesteuerten Browser verbindet. `Open Source` `kostenlos`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Go-Bibliothek für die Multi-Device-API von WhatsApp Web. `Open Source` `kostenlos`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - Automatisierung von WhatsApp Web in Node.js und TypeScript, von einem brasilianischen Team. `Open Source` `kostenlos`
- [Venom](https://go.mymarketing.click/wapi-venom) - JavaScript-System zum Erstellen von Bots für WhatsApp Web. `Open Source` `kostenlos`
- [wacli](https://go.mymarketing.click/wapi-wacli) - Kommandozeile zum Synchronisieren, Suchen und Senden von Nachrichten. `Open Source` `kostenlos`

## Fertige REST-Server

Stellen eine HTTP-API um die oben genannten Bibliotheken bereit. Dieselben Einschränkungen gelten.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - Integrations-API für WhatsApp, Open Source und in Brasilien entwickelt. `Open Source` `kostenlos`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API mit mehreren Engines und mehreren Sitzungen. `Open Source` `kostenlos`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - Selbst gehostete REST-API auf Basis von WPPConnect. `Open Source` `kostenlos`

## Kundenservice
