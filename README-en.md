## Official from Meta

The only path Meta allows for businesses to talk to customers programmatically.

- [WhatsApp Business Platform](https://go.mymarketing.click/wapi-whatsapp-business-platform) - The Cloud API documentation: sending, receiving, message templates and webhooks. `official` `API`
- [Preços da plataforma](https://go.mymarketing.click/wapi-precos-da-plataforma) - How Meta charges per message and per conversation category. `official`
- [Política do WhatsApp Business](https://go.mymarketing.click/wapi-politica-do-whatsapp-business) - What is allowed and prohibited for businesses on WhatsApp. `official`
- [Termos do WhatsApp Business](https://go.mymarketing.click/wapi-termos-do-whatsapp-business) - The terms of service for business accounts. `official`
- [WhatsApp Business](https://go.mymarketing.click/wapi-whatsapp-business) - The WhatsApp Business website, with the app and the platform. `official`

## Libraries for the official API

Open, for Meta's Cloud API.

- [whatsapp-api-js](https://go.mymarketing.click/wapi-whatsapp-api-js) - Lightweight TypeScript library with no dependencies for the Cloud API. `open source` `free`
- [whatsapp-cloud-api](https://go.mymarketing.click/wapi-whatsapp-cloud-api) - Sending and receiving through the Cloud API in PHP. `open source` `free`

## Official API providers

Meta partners that resell and operate the API. In alphabetical order.

- [360dialog](https://go.mymarketing.click/wapi-360dialog) - Direct access to the official API, billed per number. `API` `paid`
- [Blip](https://go.mymarketing.click/wapi-blip) - Brazilian customer service and chatbot platform on WhatsApp. `paid`
- [Gupshup](https://go.mymarketing.click/wapi-gupshup) - Messaging API with WhatsApp and chatbots. `API` `paid`
- [Infobip](https://go.mymarketing.click/wapi-infobip) - Omnichannel API with WhatsApp. `API` `paid`
- [Twilio](https://go.mymarketing.click/wapi-twilio) - WhatsApp through Twilio's API, along with SMS and voice. `API` `paid`
- [Zenvia](https://go.mymarketing.click/wapi-zenvia) - Brazilian communication platform with WhatsApp, SMS and email. `paid`

## Unofficial libraries

They connect as if they were WhatsApp Web. Meta does not authorize this use for businesses and the number can be banned; they are meant for personal use, testing and your own automations.

- [Baileys](https://go.mymarketing.click/wapi-baileys) - TypeScript API that speaks the WhatsApp Web protocol over a socket, without a browser. `open source` `free`
- [whatsapp-web.js](https://go.mymarketing.click/wapi-whatsapp-web-js) - Node.js client that connects through WhatsApp Web in a controlled browser. `open source` `free`
- [whatsmeow](https://go.mymarketing.click/wapi-whatsmeow) - Go library for the WhatsApp Web multi-device API. `open source` `free`
- [WPPConnect](https://go.mymarketing.click/wapi-wppconnect) - WhatsApp Web automation in Node.js and TypeScript, by a Brazilian team. `open source` `free`
- [Venom](https://go.mymarketing.click/wapi-venom) - JavaScript system for creating WhatsApp Web bots. `open source` `free`
- [wacli](https://go.mymarketing.click/wapi-wacli-2) - Command-line tool written in Go that connects as a WhatsApp Web device, stores message history in a local SQLite database with search, and sends messages, media and group messages, for terminals, scripts and AI agents. `open source` `free`

## Ready-made REST servers

They run an HTTP API on top of the libraries above. The same restrictions apply.

- [Evolution API](https://go.mymarketing.click/wapi-evolution-api) - Open source WhatsApp integration API, made in Brazil. `open source` `free`
- [WAHA](https://go.mymarketing.click/wapi-waha) - WhatsApp HTTP API with multiple engines and multiple sessions. `open source` `free`
- [WPPConnect Server](https://go.mymarketing.click/wapi-wppconnect-server) - Self-hosted REST API built on WPPConnect. `open source` `free`

## Customer service

Shared inbox for the team to reply.

- [Chatwoot](https://go.mymarketing.click/wapi-chatwoot) - Open-source support desk with WhatsApp, email, and website chat. `open source` `free`

## Free tools

No sign-up, runs in the browser.

- [Gerador de link de WhatsApp](https://go.mymarketing.click/wapi-gerador-de-link-de-whatsapp) - The wa.me link with the message already written and a QR code to print. `free` `by the author`
- [QR Code do WhatsApp](https://go.mymarketing.click/wapi-qr-code-do-whatsapp) - A QR code that opens your chat with the message ready, in PNG or SVG. `free` `by the author`
- [Nome, descrição e regras para grupo](https://go.mymarketing.click/wapi-nome-descricao-e-regras-para-grupo) - Name ideas, the description, and rules ready to paste into a group. `free` `by the author`

## Tags

Each item says what it is. The tags next to it help you choose: official when it comes from the party that sets the standard, open source when the code is published, free or paid by usage model, API and SDK by the way you integrate. Items tagged "by the author" are made by Ciro Cesar Maciel and follow the same rules as all the others.
